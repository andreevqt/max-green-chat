# Shared libraries

- `date.ts` — отображение даты и времени.
- `phone.ts` — форматирование номера телефона для интерфейса.
- `text.ts` — инициалы для аватара.

Эти библиотеки не зависят от бизнес-сущностей или пользовательских сценариев. Проверка доступных в MAX стран находится в `features/create-chat/lib/normalize-phone.ts`.
